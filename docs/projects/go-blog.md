**go-blog** 是个人博客全栈系统：后端 Go（Gin + GORM），前端含博客前台、管理端与简历站。单管理员模型，支持 Docker 部署。

因为懒得维护动态博客——既不如静态站点用 Markdown 编写方便，也不便备份——所以把之前自己做的博客系统整理出来并开源了。

## 特性

- 前台：文章、项目、搜索与简历页
- 管理端：概览、文章、站点配置与个人中心
- 技术栈：Go 1.22+ · Gin · GORM · Vue 3 · Naive UI

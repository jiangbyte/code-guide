**code-guide**（摸鱼猫泡泡）：VuePress + Theme Hope，笔记按系列归档，项目以独立文章介绍。

内容以 Markdown 为主，站点工程与文档内容同仓，便于一起迭代主题、组件与检索。

## 特性

- 笔记：语言、工具、运维、软考与实践等系列
- 项目：一篇对应一个项目，含定位、特性与示意
- 构建：`pnpm docs:dev` / `pnpm docs:build`

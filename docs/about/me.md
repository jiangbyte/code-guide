# 关于自己

现居贵州黔东南凯里。计算机科学与技术本科毕业后进入职场，目前从事 AI 全栈研发。业余维护摸鱼猫泡泡，整理常用工具、排查记录与项目结论。

### 经历

**2026.03 – 至今 · AI 全栈**

入职后参与全栈研发与交付，覆盖大文件媒体链路、ERP、分布式预约履约与内部 RAG 知识库等方向：

- **大文件上传**：针对同步上传耗时长的问题，采用自适应分片、并发上传与断点续传；会话状态存于缓存，数据直传对象存储，并完成端到端完整性校验。
- **异步媒体处理**：将探测、改封装与转码拆分为消息队列任务，由独立 Worker 消费；多节点竞争消费并以租约互斥，避免同一文件被重复处理。
- **统一存储与交付**：通过存储接口层屏蔽本地对象存储与云厂商差异，后端切换仅依赖配置；配套权限模型与文档网盘；支持容器与裸机部署，应用层可水平扩展。
- **ERP**：参与主数据、单据流转、库存 / 结算与报表等模块的需求澄清、原型 / UI 及前后端实现；完善查询条件与校验规则，跟进联调与上线。
- **分布式预约履约**：覆盖入驻、下单、派单与履约闭环；对高频列表查询结合执行计划与复合索引优化；支付回调实现幂等，避免网络重试导致重复入账；接入 AI 辅助咨询 / 业务问答；产出 PRD / 原型并跟进联调。
- **内部 RAG 知识库**：基于 Spring AI 实现多知识库管理与文件入库（原文对象存储、元数据库、解析切片与向量库）；对话侧支持会话记忆、按库过滤检索与流式输出；封装 Tools 支持业务内查询，合入前人工复核。

**2025.07 – 2025.11 · 平台研发（实习）**

实习期间参与省 / 州级平台的迭代交付与稳定性治理，业务形态覆盖监测预警与公共服务：

- **流水号与一致性**：针对并发场景下流水号冲突，基于缓存原子计数保证编号唯一且连续。
- **风险评估计算**：梳理文档并落地算法框架，对设备上报数据并行计算以缩短评估耗时；按协议对接设备，完成数据二次转换后入库。
- **数据质量**：定位业务编码错误导致的脏数据产生点，完成修复与联调，避免错误数据上送。
- **复杂查询与索引**：针对多条件查询（嵌套 OR、时间范围、模糊匹配）实现动态条件组装，并结合执行计划补全覆盖索引以保障查询性能。
- **区域策略与防重**：按管辖区域限定参与范围，基于缓存结构实现防重策略，并支持批量统计。
- **小程序联调**：按 UI 规范调整交互与接口对接，完成前后端联调与页面验收后上线。

**2024.08 – 2025.09 · 编程实训平台（主导）**

校内多语言实训系统（Java / Go / Python 等），包含 AI 辅导与代码相似度检测；负责整体推进与核心模块落地：

- **查重报告短链**：针对长链接不便分享的问题，采用 MurmurHash3 + Base62 生成短码，并结合 Redis 完成去重与查询。
- **相似计算服务**：将成对相似计算拆分为 Go 微服务；任务进入 Redis 队列，由多协程异步消费，提高吞吐并降低对主业务的影响。
- **提交接口幂等**：针对重复请求导致的重复落库，基于 Redis + Spring AOP 实现低侵入防重，保证同一业务键仅生效一次。
- **多语言词法解析**：以策略模式与工厂模式管理各语言解析器；通过 ThreadLocal 隔离请求资源，ConcurrentHashMap 复用解析对象，降低并发竞争。
- **智能辅导**：基于 Spring AI + RAG 接入题目 / 规则文档，自定义 Tools 完成题目查询与代码分析，并按会话生成结构化学习反馈报告。
